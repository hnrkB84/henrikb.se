Logga in

Adminsidan sparar inläggen direkt i ditt GitHub-repo. Den behöver en nyckel från GitHub, som bara sparas i den här webbläsaren.

  1. Öppna GitHub → ny nyckel.
  2. Under Expiration: välj 90 dagar. Då slutar en borttappad nyckel fungera av sig själv.
  3. Under Repository access: välj Only select repositories och repot .
  4. Under Permissions → Contents: välj Read and write.
  5. Skapa nyckeln, kopiera den och klistra in här.
    Välj ett inlägg till vänster eller skriv ett nytt.

    Nytt inlägg

    Tom rad ger nytt stycke. **fet text** blir fet. Länkar skriver du som [text](https://adress) eller bara adressen.
    Skriv vilka taggar du vill, åtskilda med komma. Klicka på en tagg nedan för att lägga till den.
    Till exempel adressen till projektet eller filen till printen.
    Obs: utkast är inte hemliga. De går att läsa i repot på GitHub. Skriv aldrig något privat här.
